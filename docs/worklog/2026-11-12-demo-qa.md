# Public sandbox QA preserves billing truth

**Outcome:** Check the buyer's completed purchase against Whop, then address the mobile issue found during hands-on QA.

- **Use provider confirmation.** A successful checkout return remains a hint to refresh, not proof of payment; the new payment and exact partial refund were checked against the provider and Pay.
- **Readability over squeezing.** On narrow screens, scrolling a readable table is preferable to fitting every column by breaking amounts and IDs into fragments. Keyboard users must be able to reach the controls too.
- **Keep the scope explicit.** This pass does not repeat verification-gated invoice/transfer settlement or certify production/accessibility conformance. PaidCollabs is a separate, reversible integration experiment rather than a production Stripe migration.
